# webgl experiments

random ideas, kept until they felt like objects.

a field that moves. a lock you can spin. paint that bleeds past the edge. pastel that drags. a flipbook. a breadboard that actually runs. type that won't sit still.

[web-gl-experiments.vercel.app](https://web-gl-experiments.vercel.app)

## the shelf

| | | |
| --- | --- | --- |
| 01 | grass | wind through a field |
| 03 | lock | a dial you turn by hand |
| 04 | watercolor | a brush that won't stay in the line |
| 05 | oil pastel | thick strokes, soft edges |
| 06 | flipbook | pages, flicked |
| 08 | breadboard | wires, chips, an arduino that boots |
| 09 | design tiles | a lockup you can bend |

a few more stay off the list and still open if you know the url. water. clocks in chungking. envelope.

## open it

```bash
bun install
bun dev
```

then [localhost:5173](http://localhost:5173).
